                 Von Kármán Cylinder Flow (SimFlow 5.0, PISO) – 
                 Reynolds-Based Setup 
                  
                 Physics & numerics: 
                          Physics: Incompressible · Transient · Laminar 
                          Solver: PISO (pisoFoam) 
                          Schemes: Backward (time), LUST (convection) 
                          2D: front/back = Empty 
                          Run controls: 
                           Simulation time = 5 s, Δt = 1e-3 s, Output interval = 0.025 s (= 25 steps) 
                 Parameters & etc. 
                 1.  Parameters 
                     •   d = 0.01 (m) 
                     •   nu = 1.51e-05 (m²/s) 
                     •   Re (20 or 100) 
                     •   u = Re*nu/d 
                 2.  Transport Properties 
                     •   Kinematic viscosity = nu 
                 3.  Boundary Conditions → Inlet 
                     •   Velocity Inlet 
                     •   Reference Value = u 
                     •   Outlet = 0 Pa, Cylinder = no-slip, Slip/Symmetry, front/back = Empty 
                 4.  Monitors / Function Objects 
                     •   forceCoeffs U∞ = u 
                     •   vorticity (Full Time Range → Calculate)
